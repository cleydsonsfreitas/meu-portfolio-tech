## 🚀 Sobre o Projeto

**Back End Developer | DevSecOps & Purple Team | Segurança da Informação**

Portfólio pessoal desenvolvido com foco em performance, acessibilidade e estética cyberpunk/hacker. O projeto foi construído de forma estática (Vanilla HTML/CSS/JavaScript), sem dependências complexas de build, apresentando minhas habilidades de código seguro e infraestrutura de forma interativa e moderna.

## 🛠 Tecnologias Utilizadas

- **Linguagens e Backend:**
  - Java, Python, C#
  - Spring Boot, FastAPI, .NET Core
- **Segurança e Infraestrutura:**
  - DevSecOps, Purple Team, Pentest, SAST/DAST, SDLC Seguro
  - Docker, Kubernetes, AWS, Linux/Kali
- **Ferramentas de Desenvolvimento:**
  - Git & GitHub, VS Code
  - Burp Suite, OWASP ZAP, Metasploit, Wireshark

## ⚙️ Funcionalidades

- **Home:**
  - Apresentação pessoal focada em Back-End e Cybersegurança
  - Animação interativa de cubo mágico em `.gif`
  - Links de acesso rápido para redes sociais
- **Sobre:**
  - Biografia detalhada e foco de carreira
  - Habilidades técnicas listadas de forma limpa
  - Botão de contato rápido com ícone personalizado (Pendrive)
- **Projetos:**
  - **Desafio 30:** Projetos práticos em Java, Python e C#
  - **Automação de Varredura:** Pipeline CI/CD com ferramentas de análise
  - **Laboratório de Redes Seguro:** Ambiente isolado com Kali Linux

## 🎨 Layout e Design

- **Tema:**
  - Cores principais: Preto (#000000) e Verde Neon (#00cc66)
  - Estética visual voltada ao universo Hacker/Cyberpunk
  - Design totalmente responsivo utilizando variáveis CSS puras
- **Componentes:**
  - Textos com efeito de digitação (typing effects)
  - Navegação suave (smooth scroll) entre as seções
  - Tipografia voltada para código (`JetBrains Mono`)
