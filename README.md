## 🚀 Sobre o Projeto

Portfólio pessoal focado em **Back-End Developer, DevSecOps e Infraestrutura (Cybersecurity)**. Desenvolvido com HTML, CSS e JavaScript puro (Vanilla), apresentando projetos e habilidades de forma interativa, limpa e de alta performance.

## 🛠 Tecnologias Utilizadas

- **Linguagens e Backend:**
  - Java, Python, C#
  - Spring Boot, FastAPI, .NET Core

- **Segurança e Infraestrutura:**
  - DevSecOps, Purple Team, Pentest
  - Docker, Kubernetes, AWS, Linux/Kali

- **Ferramentas e Organização:**
  - Git, GitHub, VS Code, Netlify

## 🎯 Projetos em Destaque

- **Desafio 30:**
  - 30 projetos práticos (fácil/médio/difícil) em Java, Python e C#.
- **Automação de Varredura:**
  - Pipeline CI/CD com SAST/DAST integrado para aplicações seguras.
- **Laboratório de Redes Seguro:**
  - Ambiente isolado com Kali Linux para simulação de testes e detecção.
